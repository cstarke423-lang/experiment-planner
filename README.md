# Experiment Planner

A web-based tool that helps scientists turn a research question into a structured experimental plan.

## Why I Built This

Experimental design involves keeping track of many interconnected decisions, including hypotheses, experimental groups, controls, sample sizes, assays, timelines, and analysis plans.

I built Experiment Planner to explore how software tools can make this planning process more structured and easier to communicate.

## Planned Features

- Define a research question and hypothesis
- Create experimental and control groups
- Organize experimental readouts
- Build an experimental timeline
- Generate a structured experiment summary
- Export or save an experimental plan
